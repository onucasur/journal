# Sample Journal Notes

This is the sample notes file for the journal archive viewer.

## Getting Started

- Open any group to browse its images.
- Add tags to organize your journal entries.
- Use the news clippings to attach context to each group.
- Try the ungrouped view to see images that are not yet in a group.

## Sample Groups

- Group A: tagged `sample` and `tag-a`.
- Group B: tagged `sample` and `tag-b`.

## Tips

- Press `Esc` to close the viewer or go back.
- Use the settings dialog to adjust opacity and news lookback.
- Run `./watchdog.sh` so the app can restart itself after updates.
